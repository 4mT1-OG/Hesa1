# Editable, maintained Obsidian notes

Use this area for notes that Hermes and the user may update.

- `Projects/` — active project plans and state.
- `Operations/` — trackers and procedures.
- `Memory/` — architecture notes and memory-provider evaluations (not canonical core memory).
- `Templates/` — reusable note templates.

Canonical core memories are reserved for the separate `RO/` folder; never write there. Drafts and review artifacts belong in `../Temp/` until approved.
